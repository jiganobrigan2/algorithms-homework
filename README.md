Практическая работа: Основы алгоритмов и системы Git

1. Работа с графами

1.1. Понятие графа

Граф - это математическая структура, которая состоит из объектов (вершин) и связей между ними (рёбер).

Графы применяются в разных областях:

Построение схем дорог и маршрутов.
Организация социальных сетей.
Создание компьютерных сетей.
Анализ взаимосвязей между объектами.

1.2. Ориентированные графы

Ориентированный граф - это граф, в котором каждая связь имеет своё направление.

Например, если существует переход от вершины A к вершине B, обратный переход не обязательно возможен.

Где применяются ориентированные графы:

При построении ссылок между веб-страницами.
При описании последовательности действий.
При определении зависимостей между задачами.

1.3. Взвешенные графы

Взвешенным называется граф, у которого каждому ребру соответствует определённое числовое значение - вес.

В качестве веса могут выступать:

Расстояние между точками.
Время перемещения.
Денежные затраты.
Стоимость выполнения операции.

Такие графы позволяют сравнивать маршруты и выбирать наиболее подходящие варианты.

1.4. Алгоритм поиска в ширину (BFS)

BFS (Breadth-First Search) - это алгоритм, который выполняет последовательный обход графа, начиная с выбранной вершины.

Сначала алгоритм посещает ближайшие вершины, после чего переходит к следующим уровням.

Основные характеристики BFS:

Для работы используется очередь.
Обход выполняется по уровням.
Позволяет находить кратчайший путь в невзвешенном графе.
Помогает определять достижимость вершин.

2. Система контроля версий Git

2.1. Для чего нужен Git?

Git - это инструмент, предназначенный для контроля изменений в файлах и программных проектах.

С его помощью можно:

1. Хранить историю разработки.
2. Сравнивать разные версии проекта.
3. Восстанавливать предыдущие изменения.
4. Организовывать командную разработку.
5. Разрабатывать новые функции отдельно от основной версии.
6. Объединять работу нескольких участников.

2.2. Ветки и коммиты

Ветки (Branches) - это независимые направления разработки внутри одного репозитория.

Они позволяют создавать и проверять новые возможности программы, не затрагивая основную версию.

Примеры:

main - главная ветка.
develop - ветка для текущей разработки.
feature - ветка для добавления функциональности.

Коммиты (Commits) - это записи о сохранённых изменениях проекта. Они позволяют просматривать историю работы и понимать, что менялось.

Пример создания коммита:

git add .
git commit -m "Добавлены изменения проекта"

3. Полезные команды Git

Инициализация репозитория:

git init

Добавление файлов в индекс:

git add .

Создание записи об изменениях:

git commit -m "Первый коммит"

Отображение списка веток:

git branch

Создание новой ветки и переход в неё:

git switch -c feature

Отправка изменений на удалённый сервер:

git push

Загрузка изменений из удалённого репозитория:

git pull

4. Заключение

Графы являются важной структурой данных, которая помогает описывать связи между различными объектами и решать задачи поиска маршрутов.

Алгоритм BFS используется для последовательного обхода вершин и поиска кратчайшего пути в невзвешенном графе.

Git упрощает разработку программного обеспечения, позволяя сохранять изменения, работать с версиями проекта и организовывать совместную работу программистов.
